# Bruce GeoInsights - Project Overview
## 1. Goal
To establish the official digital presence for Bruce GeoInsights, a consultancy dedicated to translating complex geological and geophysical data into actionable, de-risked strategies for mineral exploration projects.
## 2. Core Project Focus
This repository contains the source code for the company's marketing website, showcasing:
Advanced Geoscience Consulting Services.
Data Integration (AI/ML, Remote Sensing, 3D Modeling).
Commitment to ethical and responsible exploration practices.
## 3. Our Values and Acknowledgement
Bruce GeoInsights operates with integrity, acknowledgment, and respect.

* We respectfully acknowledge that our work is rooted in Kjipuktuk (Halifax) and Punamu’kwati’jk (Dartmouth), the ancestral and unceded territory of the Mi'kmaq People.

### 3.2 Inclusivity and Respect
